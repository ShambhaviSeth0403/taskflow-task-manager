# TaskFlow — Task Manager Web App

TaskFlow is a simple, responsive task management web application built using HTML, CSS, and JavaScript. It helps users organize daily tasks, set priorities, track deadlines, and manage their progress.

## Features

- Add tasks with a name, priority, and deadline.
- Mark tasks as completed and undo completion.
- Delete tasks when they are no longer needed.
- Filter tasks by All, Active, and Completed.
- Save tasks in browser local storage.
- Responsive layout for desktop and mobile screens.

## Technologies Used

- **HTML5** — Webpage structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Task management and interactions
- **Local Storage** — Save tasks between browser refreshes

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Add tasks and start organizing your day.

No additional dependencies or installations are required.
